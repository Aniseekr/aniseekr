# 主畫面小工具「接下來」— E2E 計畫

範圍：iPhone 18 Pro 模擬器（iOS 27.2），繁中。這次有原生變更（新增 widget extension 與 App Group），
所以重跑 `expo prebuild -p ios` 並用 `xcodebuild` 編 Release 模擬器版。
免費狀態跑真實程式碼；Pro 狀態沒有沙盒購買，只能把 `isPro` 暫時強制後重新打包 JS。
Android、web、實機、簽章版不在這輪。

資料：`user_anime` 寫入本季還沒播的番（ID 與時間取自 App 的當季快取），狀態「在看」。
獨立驗證：小工具上的時間對快取裡的開播時間；提醒對 `scheduled_notifications` 表。

| 案例 | 步驟 | 預期 | 驗證位置 |
| --- | --- | --- | --- |
| W0 編譯 | 編 Release 模擬器版 | 成功，App 內含 `PlugIns/ExpoWidgetsTarget.appex` | 指令輸出 |
| W1 App 正常 | 裝新版，開個人頁、統計 | 正常顯示，沒有紅屏或閃退 | 截圖 |
| W2 免費鎖定 | 主畫面加入小工具 | 顯示升級 Pro 的那句話，沒有任何番名 | 主畫面截圖 |
| W3 Pro 清單（強制） | 兩部「在看」，開 App 後回主畫面 | 中尺寸列出兩部，集數與時間等於快取；小尺寸只列最近一部 | 主畫面截圖 vs 快取 |
| W4 沒有在看 | 刪掉測試列，開 App 後回主畫面 | 顯示「在看的番近期沒有新集數。」 | 主畫面截圖 |
| W5 點擊 | 點小工具 | 開到追番頁 | 截圖 |
| W6 提醒回歸 | 載入邏輯改成共用後，重跑自動提醒 | 兩部「在看」各一則，時間＝開播前 15 分鐘 | 資料表 |

## 這裡跑不了的

- 到開播時間小工具自動換下一筆：要等到當晚。
- 實機與上架簽章：extension 的 App ID、App Group、描述檔要在 Apple 開發者帳號建立，需要帳號登入。
- Android 小工具：這輪沒開。
