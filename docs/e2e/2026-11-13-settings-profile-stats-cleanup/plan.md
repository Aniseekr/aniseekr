# 設定／個人頁／統計頁整理 — E2E 計畫

範圍：iPhone 18 Pro 模擬器，開發版 App + 目前工作目錄的 Metro bundle。不登入任何平台、不觸發同步、不改遠端資料。
驗證位置一律為畫面截圖（UI 值）。

| ID | 目標 | 步驟 | 預期可觀察結果 |
| --- | --- | --- | --- |
| C0 | 基線 | 啟動 App，確認 bundle 是這次的變更 | 個人頁「統計」標題列右側有「完整統計」按鈕（舊版是獨立卡片） |
| C1 | 設定首頁版型 | 個人頁 → 齒輪 | 置中標題的 ScreenHeader；分區依序為 帳號與同步／內容／外觀／通知與儲存／關於；標題下沒有「長按」提示 |
| C2 | 同步與匯入不再隱藏 | 在設定首頁點「同步中心」、返回、點「匯入精靈」 | 兩頁皆能開啟並顯示各自標題 |
| C3 | 開關仍可用 | 切換「包含遊戲」再切回 | 開關狀態改變、再改回 |
| C4 | 進階頁 | 設定 → 關於 → 進階 | 只有 診斷（相機診斷）與 開發工具（Design Tokens、Live Preview）；點 Design Tokens 可開啟 |
| C5 | 捷徑預設與可選清單 | 個人頁捷徑 → 編輯 → 點一格 | 清單含 備份、觀看平台、趨勢、年度回顧；不含 條款、致謝、設計參數、主題預覽 |
| C6 | 捷徑可排列 | 在 C5 的清單選「趨勢」→ 完成 → 點該格 | 該格變成趨勢並開啟趨勢頁 |
| C7 | 御宅 DNA 捷徑 | 點「御宅 DNA」捷徑 | 開啟統計頁（不是 404／unmatched route） |
| C8 | 統計頁有資料時的版面 | 資料庫需有收藏；開統計頁 | 無彩色漸層卡；數字卡、狀態圓環、展品格狀卡皆為墨線卡片；沒有「Top N%」「Year in review · 年份」字樣 |
| C9 | 統計子頁頁首 | 從統計頁點「名人堂」 | 置中標題的 ScreenHeader、可返回 |

清理：C3、C6 改動的本機偏好在測完後改回。
