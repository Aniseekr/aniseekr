# E2E plan — 頁面 IA 重整（類型入口／分數／追番設定／空狀態）

裝置：既有 iPhone 18 Pro 模擬器、開發版 AniSeekr，JS 由本工作目錄的 Metro 載入（包含本次未 commit 的變更）。不登入、不碰遠端資料。

| ID | 目標 | 步驟 | 預期 | 驗證位置 |
|---|---|---|---|---|
| G1 | 探索首頁類型網格 | 開啟探索 tab，捲到「依類型探索」 | 兩欄封面方塊 6 格＋「全部 N 個類型」；標題右側「為你挑選」；區塊在本週熱門之上 | 截圖 G1 |
| G2 | 類型頁 | 點第一個類型方塊 | 標頭為類型名稱＋副標「依 AniList 人氣排序」；封面；大按鈕「開始滑卡」；說明一行；「最熱門」列表含名次、分數 x.x | 截圖 G2 |
| G3 | 卡堆標頭與提示 | 按「開始滑卡」 | 標頭中間顯示類型名稱；第一張卡有「點看詳情」；分數為 x.x（不是 83） | 截圖 G3 |
| G4 | 提示只出現一次 | 左滑一張 | 第二張卡沒有「點看詳情」 | 截圖 G4 |
| G5 | 繼續滑卡 | 返回類型頁 | 按鈕變「繼續滑卡 · 已滑 1 張」 | 截圖 G5 |
| S1 | 追番設定串接 | 播出表 → ⋯ → 設定 | 有「集數提醒」開關、「提醒時間與通知設定」、「資料來源」；沒有成人內容開關 | 截圖 S1 |
| S2 | 提醒開關同一來源 | S1 關掉集數提醒 → 點「提醒時間與通知設定」 | 設定 → 通知頁的集數提醒也是關的；之後開回去 | 截圖 S2（cleanup：恢復開啟） |
| S3 | 播出表列 | 播出表今天 | 每列一行「第 N 集 · 今天 HH:MM」，沒有第二行 | 截圖 S3 |
| L1 | 收藏空狀態 | 收藏 tab（本機 0 收藏） | 標題「收藏還是空的」＋三個入口 | 截圖 L1 |
| P1 | 個人頁統計 | 個人 tab（0 資料） | 一行引導＋「去滑卡」，不是三個 0 | 截圖 P1 |

注意：G4 的左滑會在本機記錄「已看過」（swipe_seen），不影響遠端資料。
