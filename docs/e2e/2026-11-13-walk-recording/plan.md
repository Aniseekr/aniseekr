# 巡禮軌跡記錄＋行程路線 E2E 計畫（2026-11-13，階段 3、4）

裝置：iPhone 18 Pro 模擬器（iOS 27）。Build：這次重新 prebuild（`UIBackgroundModes: location`、expo-task-manager）後編的 Release 模擬器 build；JS 以工作目錄 `expo export:embed` 換入。
Bundle：R＝工作目錄原樣；F＝R 加 `PREMIUM_ENABLED: false`（Pro 功能全開，用來跑 GPX 匯出）；B＝R 加 JS `fetch` 一律失敗。F、B 只改匯出檔。
走路：`xcrun simctl location booted start --speed=3 <路徑點…>`（高山市）。
基線：氷菓 現地 5 · 補記 1；2.5次元的誘惑 補記 1；沒有任何軌跡。「我的作品」含氷菓（已有章），不含シキザクラ。
