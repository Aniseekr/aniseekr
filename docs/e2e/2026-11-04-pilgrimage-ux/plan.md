# 巡禮 UX 重整 — 計畫（2026-11-04）

尺寸：L。順序：相機 → 作品頁 → hub，每段結束跑一次模擬器 E2E。相機實機部分需要使用者手上的裝置。

## 產品決定（已用建議答案先做，可推翻）

1. **橫的參考圖 → 相機自動切橫拍？** 建議：是。動畫截圖幾乎都是 16:9 橫圖，直拿手機時疊圖只剩中間一條。匯入橫圖時把方向鎖成橫向，設定裡可改回 AUTO。
2. **匯入的截圖要不要記在這個景點上，下次開相機直接帶出？** 建議：要。現在關相機就刪，回來要重新匯入。改成「每個景點記住最後一張」，換圖時才刪舊的。
3. **作品頁預設比例？** 建議：地圖約佔 2/3，清單 sheet 停在只露出標題列＋篩選＋第一列的位置；往上拉才是清單。

## Phase 1 相機（使用者最優先）

- 無參考圖：全螢幕即時預覽。只留：頂列（關閉／地點名／閃光／拍攝模式／設定）、一顆輕量「匯入這一幕的截圖 · 第 N 集 mm:ss」膠囊、焦段、快門列。
- 有參考圖才出現：REF 縮圖、疊圖模式輪播、該模式的小控制、透明度。
- 計時／比例／方向／指引那排 chip 拿掉：計時與比例本來就在設定 sheet；方向與 GPS 指引移進設定 sheet。
- 匯入不再 `router.replace`（會重開相機 session、黑一下、HUD 全重置）；改成原地換參考圖，直接開相簿（跳過只有一顆按鈕的 sheet）。
- 寫死的中英文字串（鏡頭切換失敗、疊圖模式提示、描邊錯誤）改走 i18n。

## Phase 2 作品頁

- sheet 預設 detent 降低，地圖變主角；接近提示改成地圖上的小膠囊，不再蓋住半張地圖。
- 列表列：只留「第 N 話 · 距離」，地址與可信度移到展開後；把「單一來源比對／已確認」改成白話。
- 標頭不再重複數量（分段控制已有）。
- 點列 → 地圖飛到該點並放大標記；點地圖標記 → 列表捲到該列並展開；「拍照比對」直接進相機。
- 小 cluster 點（12–16px）點不到：加大觸控區、2 個以上就顯示數字。

## Phase 3 Hub

- 「附近」改成真的地圖預覽卡（MapLibre，不可互動，點了進地圖）；沒定位權限時就是地圖本身加一顆「開啟定位」膠囊，不再是一整張文字卡。
- 標題列的地圖小按鈕拿掉（地圖卡就是入口）。

## 相機邊界情況盤點（PhotonCamera 對照，只學概念、不抄程式；它是 Apache-2.0）

PhotonCamera 的做法：觀景窗大小 = 輸出比例（所見即所得），放在頂列下方、放不下就置中；切鏡頭／比例時用過場遮住 session 重建；回前景時主動檢查並復原相機；方向偵測忽略「手機平放」以免存檔方向亂跳；UI 鎖直向、只轉圖示。
