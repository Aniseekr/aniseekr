- 裝置：Samsung S20 FE（Android 13）。手機的 Photo Picker 模組版本是 361153920，沒有新的「包含位置」選項。
- Build：debug dev client `com.kidneyweakx.aniseekr.e2e`，包含新的原生模組 `AniseekrPhotoImport`。JS 用分支工作目錄。

**測試資料**：4 張產生的 JPEG（純色加 `E2E-IMPORT-n` 字樣，不是個人照片），放在 `/sdcard/Pictures/AniseekrE2E/`。
