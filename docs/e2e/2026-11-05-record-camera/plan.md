裝置：Samsung S20 FE（Android 13）。Build：debug dev client `com.kidneyweakx.aniseekr.e2e`，JS 是分支 `claude/pilgrimage-ux-85ef2a` 的工作目錄（P1a 未 commit 的改動）。

| 案例 | 步驟 | 預期 | 驗證位置 |
|---|---|---|---|
| R1 自由相機預設 | 開 `/pilgrimage/capture` | 標題「自由拍攝」；快門上方是「紀錄｜動漫」，選中紀錄；沒有匯入膠囊、REF、距離方位 chip | 截圖 |
| R2 紀錄快門 | 按快門 | 留在相機；toast「已記錄」；左下縮圖變成剛拍的 | 截圖、logcat 沒有錯誤 |
| R3 縮圖 | 點縮圖 | 開剛拍那張的預覽，底部有分享 | 截圖 |
| R4 切到動漫 | 點「動漫」 | 不換頁；出現匯入膠囊；切回紀錄就消失 | 截圖 |
| R5 從景點進入 | 作品頁 → 景點卡 → 拍照比對 | 開在動漫模式；切到紀錄後拍照 → toast「已記錄」加景點名 | 截圖 |
| R6 手帳歸檔 | 開手帳 | R5 那張歸在該作品／景點底下，「去過的場景」至少 1 | 截圖（不含 GPS 座標的畫面） |
| R7 相機 tab | 若 tab 列有相機，切過去 | 沒有關閉鈕；快門不被 tab 列蓋住；切到別的 tab 後相機停止 | 截圖 |
