# 紀錄相機＋時間流手帳＋看得到的分享 — 計畫（2026-11-05）

使用者故事：去了靜岡，隨手拍，回頭看。
1. 匯入相片，靠 GPS 對到是哪部動畫的聖地。
2. 拍照時不必先選「紀錄或動漫」；記錄要快、要有時間流，之後能整理成聖地巡禮相簿。
3. 分享要看得到。

大小：L（新的相機形狀＋手帳資料檢視＋原生 picker）。分階段做，每階段都要實機 E2E。

## 從 PhotonCamera 學到的（只學做法，不抄程式；Apache-2.0、Kotlin）

**排版**
- 觀景窗是一張固定比例的卡，比例等於存檔比例（4:3／16:9），所見即所得。
- 控制項是量好實際高度後排在卡下方的黑區，由上到下：縮放列 → 參數列（48dp）→ 快門列（72dp 快門）→ 模式切換。
- 疊在預覽上的只有對焦框、水平儀、格線。我們現在是把所有東西浮在全螢幕預覽上，所以看起來亂又陽春。

**濾鏡**
- 在觀景窗上左右滑就能切 LUT，預覽即時套用，濾鏡名稱短暫浮出。
- 判斷橫向手勢有門檻，避免和點擊對焦、捏合縮放衝突。

**快門到縮圖**
- 拍完不跳頁：縮圖飛進左下相簿鈕，處理中顯示進度環，可以連續拍。

**模式**
- 底部用 3 段膠囊（專業／拍照／錄影），選中的那段用滑塊動畫。

**邊界情況**
- 切鏡頭或比例時，用過場遮住 session 重建。
- 回到前景時主動檢查相機並復原。
- 手機平放時忽略方向變化。
- UI 鎖直向，只轉圖示。

**相框（Frame）**
- 照片外加邊框和拍攝資訊。這正好是分享圖該有的樣子。

## 現況（讀程式碼，未上機）

| 問題 | 現在的樣子 |
|---|---|
| 兩台相機 | 「探索相機」（`StandaloneCaptureScreen`，自由拍）和「比對相機」（`compare/[spotId]`，1800 行）。要比對得先開「參考圖」sheet 選一張，再 push 到另一頁。這就是「選紀錄或動漫」不順的原因。 |
| 拍完會擋路 | 存檔加 toast 之後，若 150m 內有 Atlas 景點，就跳出卡片問「掛到 X？」，蓋住快門。不按的話，這張就留在「自由拍攝」。 |
| 匯入沒有時間和位置 | `importLibraryPhoto` 只複製檔案、不讀 EXIF，時間記成匯入當下，也沒有位置。故事 1 現在做不到。 |
| 手帳沒有時間流 | 依作品分資料夾，另有一個「自由拍攝」資料夾。沒有依日期或地點分段，也沒有「這趟旅程」。 |
| 分享藏起來 | 唯一入口是比對預覽頁右上角的小圖示。自由拍沒有分享；手帳要點進照片才會看到那個圖示。 |

已經有、可以直接用的：
- 每筆拍攝紀錄都有 `capturedAt`，以及 `userLocation` 或 `spotGeo`。
- `findNearestCachedSpot` 查的是全部 Atlas 景點（`spotsLite`），不只是開過的作品。
- trace.moe 場景辨識已經有了。

**平台限制（GPS）**
- Android 系統相片挑選器預設會清掉位置資訊。
- 2026-08 起的 Mainline 更新新增 `MediaStore.EXTRA_PICK_IMAGES_REQUEST_LOCATION_METADATA_ACCESS`：挑選器會問使用者要不要附上位置，選擇會依 app 記住。
- `expo-image-picker` 不會帶這個 extra，需要一小段原生程式碼。舊版 Mainline 的手機拿不到位置。
- iOS PHPicker 預設附帶位置，使用者可以在選圖時關掉。這點需要實機確認。
- 沒有位置的照片就標「沒有位置」。**不能**用手機目前的 GPS 代替（Rule 8）。

## 新的形狀

**相機：一台，預設是「紀錄」**
- 按快門就存檔並寫 log（時間、GPS、附近聖地），不問任何問題，縮圖飛進左下。
- 「動漫」是一種模式或濾鏡，不換頁：
  - 底部膠囊在「紀錄｜動漫」之間切換，也可以在觀景窗上左右滑。
  - 在動漫模式下，若附近有聖地，自動帶出最近景點的場景圖當疊圖；有記住的參考圖時優先用它；都沒有就顯示「匯入這一幕的截圖」膠囊。
- 排版照 Photon：觀景窗卡等於存檔比例，控制項放在下方黑區。這也一併解決目前「預覽 cover、存檔比例不同」的問題。

**手帳：時間流**
- 預設檢視是時間流，依日期分段，段內依地區（由 GPS 反查城市）細分。
- 每張照片顯示時間，以及配對到的作品／景點標籤；沒有位置的照片標「沒有位置」。
- 「整理成巡禮相簿」：選一段日期（一趟旅程）後，依作品分章，產生一本可以分享的相簿。
- 匯入可以多選：讀 EXIF 的時間和 GPS，批次配對後依「拍攝時間」插進時間流。

**分享：看得到**
- 預覽頁底部的主要動作改成「分享」和「儲存」並列，取代目前右上角的小圖示。
- 時間流裡的每張照片、每本相簿都有分享。
- 分享圖做成相框：照片＋作品＋景點＋集數＋日期。

## 待決定（每題附推薦）

1. **拍完怎麼配對？**
   - 推薦：自動掛到 150m 內最近的 Atlas 景點，時間流上顯示標籤，可以改或移除。
   - 其他選項：只標「附近有 X」但不掛上；或維持現在的確認卡。
2. **相機要不要合併？**
   - 推薦：合成一台，「動漫」是模式。比對相機的疊圖、REF、輪播都搬進動漫模式。
   - 其他選項：保留兩台，只改排版。
3. **Android 匯入要不要拿 GPS？**
   - 推薦：做原生 picker 支援新的 location extra。只有 2026-08 Mainline 之後的機器有，舊機標「沒有位置」。
   - 其他選項：先只做 iOS。
